Imagine a .NET language that feels as intuitive as Go, Kotlin, or Swift. G# aims to be exactly that, compiling directly to managed assemblies while bringing modern ergonomics.
It features structured concurrency, explicit numeric types like int32 and uint64, and familiar syntax for functions and pattern matching. Forget the guesswork with value sizes; every type is explicit.
This language includes a complete tooling ecosystem, from a command-line compiler to a VS Code extension and a language server. It truly offers a fresh perspective on developing robust applications within the .NET ecosystem.
