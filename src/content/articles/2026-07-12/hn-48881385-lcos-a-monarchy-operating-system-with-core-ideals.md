Creating an operating system is a huge undertaking, but Bryan Lunduke has released LCOS, a highly opinionated Linux system. It is built on Devuan and adheres to some strict ideals: no AI, no online accounts, no Systemd, and a distinct 90s UI.This project demonstrates a unique approach to software architecture and system design, focusing on simplicity and user control over modern conveniences. It is a monarchy-driven project, preventing external influence, which is a provocative stance in open source.The LCOS challenges conventional OS design by prioritizing specific user freedoms and a nostalgic aesthetic. It offers a fresh perspective on what an operating system can be when designed with a very specific, anti-mainstream philosophy.Explore this fascinating, contrarian operating system design.
