"I hate coding agents. Is this a skill issue?" This "Ask HN" question sparked a fascinating debate, revealing a split in the engineering community. Many engineers express significant frustration with the current state of AI agents for coding.

The consensus points to common issues: debugging agent "thoughts" is opaque, prompt engineering complexity, and agents often failing on subtle context or complex logic. This makes iterative development and fault tolerance challenging.

However, others highlight that leveraging agents effectively requires a different skillset - more akin to orchestration and high-level problem decomposition, rather than direct imperative coding. It is a nascent field, and the tooling is still maturing, requiring engineers to adapt to new paradigms for productivity gains.
