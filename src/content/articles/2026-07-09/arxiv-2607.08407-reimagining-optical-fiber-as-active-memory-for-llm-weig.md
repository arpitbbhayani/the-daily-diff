Generative AI is creating immense pressure on DRAM supply and pricing. What if we could ditch DRAM for LLM weights entirely?

"Fiber Memory" proposes a radical new architecture: using optical fiber as an active, recirculating delay-line memory. It is designed specifically for immutable data like large language model weights.

By leveraging space-division multiplexed multi-core fibers, co-packaged optics, and all-optical regeneration, Fiber Memory could eliminate redundant weight storage across 10,000 AI accelerators.

It promises to reduce weight-delivery energy by over 70% compared to traditional HBM3e configurations. This is a game-changer for LLM infrastructure and hyperscale data centers.
