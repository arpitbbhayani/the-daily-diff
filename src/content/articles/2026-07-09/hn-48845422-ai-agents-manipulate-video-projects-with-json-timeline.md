FableCut just launched: a zero-dependency browser video editor that AI agents can drive. The entire timeline is a single JSON document, editable via MCP/REST, with a live-reloading UI updating in ~150 ms.This is a brilliant demonstration of how AI agents can control complex creative software. It flips the traditional 'AI video' paradigm, making the project file itself the interface for agentic manipulation.For engineers exploring applied AI, this offers concrete insights into designing open, agent-friendly tools. It is about empowering AI to truly create and iterate with human-like fluidity.
