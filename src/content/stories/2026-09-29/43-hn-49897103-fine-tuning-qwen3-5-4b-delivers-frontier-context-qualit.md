Contextual retrieval improves RAG accuracy by prepending document-level context to chunks before indexing, but running commercial frontier models over millions of meeting minutes creates severe cost bottlenecks.

When replacing Gemini Flash-Lite in a production municipal minutes pipeline, the author fine-tuned Qwen3.5-4B on synthetic context generated by Claude Opus 5.5. Using reinforcement learning where Opus graded output contexts specifically to penalize hallucinated inferences, the fine-tuned 4B model produced fewer extraction errors while cutting inference costs by 71 percent.

The key engineering lesson is that specialized local models trained with strict negative reinforcement against guessing can outperform general-purpose commercial APIs on constrained retrieval tasks.

For teams building high-throughput indexing pipelines, small model distillation combined with automated evaluation loops provides a clear path to cost sustainability without degrading retrieval precision.
