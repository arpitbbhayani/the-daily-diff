Debugging AI agents can often feel like peering into a black box, but AgentLens offers a significant leap forward. This tool allows you to replay and compare runs of AI coding agents like Codex, capturing crucial data points such as executed commands, generated code diffs, and token usage.

Being able to see exactly what an agent 'read,' 'ran,' and 'changed' helps demystify its decision-making process. This is invaluable for identifying why an agent succeeded or failed, understanding where runs diverged, and ultimately improving agent reliability and performance.

Furthermore, the ability to export redacted, standalone HTML artifacts makes sharing these insights with teammates or for pull request reviews incredibly straightforward. This is a highly practical tool for any engineer building or working with AI agents, bridging the gap between agent output and actionable debugging.
