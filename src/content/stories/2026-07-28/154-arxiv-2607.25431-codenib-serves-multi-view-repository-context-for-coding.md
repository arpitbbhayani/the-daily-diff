Coding agents often struggle with efficiently managing and retaining context from rapidly evolving code repositories. They spend too much time re-indexing and searching, leading to high token usage and slow performance.

CodeNib proposes a multi-view data system that tackles this head-on. It builds lexical, dense, and structural views for each repository commit, allowing for dynamic updates and serving ranked search and symbol navigation through a single, optimized runtime.

The results are compelling: CodeNib achieves 8.7 times faster graph updates and 25.4 times faster vector updates compared to independent rebuilds. Crucially, it helps agents localize context with 50-87 percent fewer trajectory tokens. This is a game-changer for building truly efficient and responsive coding assistants.
