A major headache with LLM agents is workflow misalignment: agents skipping steps, taking unsupported branches, or misusing tools, even when given clear natural-language instructions. They interpret prompts, but do not execute them rigorously.

COVENANT proposes a radical solution: treat workflow instructions not as prompts, but as source programs. It compiles these instructions into an abstract syntax tree (WAST) and a control-flow graph (WCFG). Then, a runtime controller interprets the WCFG, validating every proposed agent action against the explicit workflow requirements.

This compiler-and-interpreter architecture significantly boosts benchmark success from 50 percent to 83.33 percent and cuts workflow misalignment by 62.75 percent relative. It offers a structured, auditable way to enforce process adherence, moving agent alignment from "hopeful prompting" to "guaranteed execution."

This is a paradigm shift for anyone designing production-grade LLM agents. It provides a robust blueprint for building agents that are not only capable, but also reliably compliant with your business logic.
