Training LLM agents for complex, long-horizon tasks often hits a wall due to sparse final rewards, making effective credit assignment incredibly difficult. How do you teach an agent precisely what it did right or wrong at each step? A new technique called CAST (Credit Assignment from Solver Teachers) offers an ingenious solution.

CAST leverages game solvers to provide dense, turn-level feedback by observing changes in the solver's state value. This transforms abstract success into concrete advantages for each action, which are then injected into reinforcement learning pipelines. It is essentially on-policy distillation from an expert, but only requires scalar values, not complex logits.

The results are compelling: CAST significantly outperforms traditional methods in various games and zero-shot tasks like ALFWorld and WebShop. For anyone designing or implementing multi-agent systems, this method provides a powerful paradigm for accelerating learning and achieving more capable, robust LLM agent behaviors.
