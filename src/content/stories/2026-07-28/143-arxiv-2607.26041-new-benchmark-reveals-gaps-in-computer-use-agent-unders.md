Current benchmarks for computer-use agents often only measure end-task success, but this misses a critical question: do these agents truly understand the *causal transitions* produced by their actions in a GUI? Desktop-Delta Bench (DDB) aims to fill this gap.

DDB provides a diagnostic layer that assesses an agent's ability to reconstruct the task-relevant changes after an action. This is vital for rejecting stale observations, verifying progress, and recovering from failures, especially when dealing with asynchronous inference and rendering.

The benchmark identifies three key failure dimensions: state verification, source tracking, and context-aware control. Its findings reveal consistent gaps in current models, showing that inferring action family is harder than locating it. This is a crucial step for building more reliable and robust desktop AI agents.
