Imagine a single eBPF policy program coordinating data movement and execution across GPUs, DPUs, NICs, and CXL switches. fabric_ext presents precisely this: a revolutionary eBPF middleware for GPU-CXL fabrics, treating the fabric itself as the cluster driver.

The core innovation is a 'semantic movement graph' that describes dataflow characteristics—bytes, stride, reuse, transformations like Quantize or Replicate. This graph is compiled into per-device eBPF programs, enabling cross-layer OS policies that are specialized for the hardware and workload, moving beyond rigid, siloed control.

This framework is a game-changer for high-performance computing and LLM infrastructure. The canonical stress case, LLM prefill, involves intricate data movement for attention, FFN, and compressible intermediates. fabric_ext provides the control plane to optimize these interactions at an unprecedented depth, unlocking new levels of performance and efficiency for next-generation AI workloads. This is a must-read for anyone building systems at the cutting edge of distributed AI.
