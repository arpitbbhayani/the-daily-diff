Generalist manipulation policies built on large AI backbones often struggle with reactivity because their perception-to-action pipeline is too slow for real-time control. $π\mathbf{R}^2$ solves this with an ingenious system design, making these policies both reactive and real-time.

The core idea is to split the policy's conditioning into two channels: a fast, fresh proprioception channel (like joint states) and a slower, asynchronously updated vision-language feature channel. This allows the policy to react to immediate sensory input within an action chunk while tolerating the latency of complex visual processing.

Combined with a latency-adaptive flow schedule, $π\mathbf{R}^2$ achieves replanning rates roughly four times faster than base policies, translating to a 23-30 percent increase in success rate for real-world manipulation tasks. This is a game-changer for engineers building responsive embodied AI.
