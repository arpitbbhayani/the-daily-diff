Everyone assumes one-sided RDMA is king for disaggregated memory databases due to its zero remote CPU involvement. But what if two-sided RDMA is actually *striking back*?

Lotus, a new system, proves that by intelligently leveraging two-sided RDMA with lightweight caching and efficient batching, you can achieve up to 8.2 times higher throughput and 42.9 times lower p999 tail latency than state-of-the-art one-sided approaches.

This work completely re-evaluates the long-standing debate. It shows that crucial system functions like starvation prevention, priority-based scheduling, and preemption, which are hard with one-sided RDMA, become feasible and performant with a smart two-sided design. This is a game-changer for high-performance distributed database architecture.
