Getting LLMs to generate correct code is one thing; getting them to generate optimized code is an entirely different beast. This paper cracks the code on applying Reinforcement Learning (RL) for actual code optimization, overcoming major hurdles like measurement noise and reward sparsity that plague typical RL setups.

The key innovations involve a new benchmark, DMC-Optim, designed with large optimization tests and a calibrated sandbox for precise timing. They also crafted a novel reward system that effectively combines correctness and speed, leveraging an offline simulator to predict promising configurations.

The results are striking: significant improvements in strict pass rates for optimized code. For instance, CWM 32B saw a 125% relative improvement at the top-30% percentile. This is not just incremental progress; it is a blueprint for building AI coding assistants that genuinely produce faster, more efficient software.
