Ensuring trustworthiness in embodied intelligence, where AI systems interact physically with the real world, goes far beyond mere task completion. It demands "sustained safe success" under varying conditions, and this paper provides a robust systems framework to achieve it.

The framework breaks trustworthiness down into four interdependent layers: the model layer for calibrated actions and safety preferences, the system layer for reliable execution and hardware safeguards, the evidence layer for substantiating claims, and the deployment layer for runtime monitoring and governance.

This holistic view, which explicitly integrates lessons from dependable computing, distributed systems, and autonomous driving, helps architects and engineers approach safety-critical AI development systematically. It is a principled guide for building intelligent agents that you can truly rely on.
