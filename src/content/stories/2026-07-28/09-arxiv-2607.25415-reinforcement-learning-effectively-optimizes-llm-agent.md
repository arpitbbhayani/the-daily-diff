You are using frozen LLMs but want your agents to adapt and learn new domains without expensive fine-tuning or risky self-modifying code. How do you make that happen with auditable control?

This paper delivers exactly that: a comprehensive control system, a dataset, and a deployment recipe for optimizing the harness around frozen LLM agents. It treats the harness (prompt, tools, memory, planning, verification) as a human-legible action space and learns an optimal policy over it using sample-efficient reinforcement learning.

The system uses DSPy for context assembly and evaluates across diverse domains like tool-use, code generation, and multi-hop QA, showing impressive adaptive capabilities. Critically, it does this with a multi-objective reward function, balancing task success, cost, and compliance.

This is not just theory; it is a practical blueprint, complete with open-sourced code, logs, and a provider-agnostic deployment guide. If you are building production LLM agents, this offers a powerful and auditable path to making them smarter and more efficient.
