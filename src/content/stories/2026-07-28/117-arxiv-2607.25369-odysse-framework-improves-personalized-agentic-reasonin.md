Building AI agents that handle ambiguous, personalized requests over long interaction sequences is incredibly hard. Many existing methods struggle with credit assignment across steps.

A new framework, ODYSSE, tackles this by introducing Episode-wise GRPO (ESPO). Instead of optimizing individual steps, ESPO uses episode-level rewards and episodic advantage estimation to guide decisions, allowing upstream evidence to impact downstream actions effectively. This is a crucial shift for multi-step tasks.

ODYSSE has shown significant performance gains on challenging personalized GUI reasoning tasks, outperforming both specialist and general-purpose models. If you are wrestling with agentic systems that need to decode user preferences across many interactions, this paper offers a compelling, practical approach.

This is a real step forward for creating more adaptable and user-aware agents.
