LLM agents are only as good as the tools they wield, but current retrieval methods often treat tools as isolated entities. This paper challenges that by proposing HYSET, a novel hyperedge-based approach that retrieves entire sets of tools, evaluating their joint utility. This is a game-changer for agent pipelines.Current systems often score each tool in isolation or build sets sequentially, missing critical interdependencies. HYSET formulates this as query-conditioned hyperedge prediction on a tool co-invocation graph, allowing it to capture size-dependent compatibility and select optimal tool combinations.This design is a pre-selection module, meaning no modifications are needed for your existing agent. Expect significant boosts in retrieval performance and end-to-end task success, proven on ToolBench, while also gaining zero-shot and few-shot transfer capabilities.Stop building agents with isolated tools; think holistically for real-world impact.
