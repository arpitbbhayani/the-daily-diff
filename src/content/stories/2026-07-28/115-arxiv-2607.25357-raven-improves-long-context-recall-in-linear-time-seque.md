Achieving reliable long-context recall in linear-time sequence models is a persistent challenge. Current approaches either suffer from memory interference (state-space models) or hard eviction (sliding-window attention).

Raven proposes an innovative solution: sparse memory routing. This model maintains a fixed set of memory slots and, at each step, intelligently decays and updates only a selected subset of these slots via learned, input-dependent routing. This smart allocation strategy significantly reduces interference while preventing abrupt evictions.

The results are compelling. Raven is competitive with or outperforms prior linear-time baselines across recall-intensive benchmarks, maintaining effectiveness even when extrapolating to context lengths 16 times its training length. This has profound implications for designing more efficient and capable LLM architectures.

This mechanism is a critical step forward in addressing one of the most significant bottlenecks for real-world applied AI systems that require deep, long-range contextual understanding.
