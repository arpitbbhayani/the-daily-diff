Building enterprise AI agents? It is not just about tool use or retrieval anymore. A new benchmark, WorkSurface-Bench, highlights "surface routing" as a critical, overlooked capability for real-world agent success.

Enterprise agents must integrate knowledge from diverse sources: documents for facts, tables for computation, and graphs for relationships. This benchmark rigorously tests if agents can *select the right source* before even attempting an answer.

The findings are crucial: while agents achieve 99% accuracy in surface selection with gold-constrained tools, their answer accuracy remains 56-75%. This reveals that picking the right tool is necessary but far from sufficient. Better context engineering and "surface hints" significantly improve answer quality. This is a must-read if you are wrestling with agent performance on complex, heterogeneous enterprise data.
