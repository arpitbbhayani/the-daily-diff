Automating Kubernetes security remediation with LLMs sounds like a dream, but there is a hidden danger: patches generated in isolation can break critical runtime dependencies. This paper proves that live cluster topology context is not just helpful; it is absolutely essential for safe, effective automated patching.

Introducing KuTIE, a system that feeds LLMs real-time data like Istio call edges and service-account bindings. The results are astounding: topology-dependent patch correctness soared from 11.1% to 78.0% with this context.

This gap holds true across various dependency classes, from credential policies to role-based access control. The lesson is clear: for LLM agents to act reliably in complex systems like Kubernetes, they need to be deeply grounded in the real-time operational state. This research provides a crucial blueprint for building truly intelligent and non-destructive automation.
