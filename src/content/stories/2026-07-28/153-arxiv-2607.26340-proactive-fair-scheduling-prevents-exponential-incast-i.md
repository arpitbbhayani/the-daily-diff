Large language models using Mixture of Experts (MoE) architectures are hitting a surprising network bottleneck: an exponential incast phenomenon caused by standard round-robin scheduling. This significantly hampers performance and resource utilization.

This paper dives deep, revealing how this incast specifically emerges in MoE traffic patterns. It then introduces a proactive, fair, rate-based scheduling framework designed to completely eliminate incast and keep network links near 100 percent utilization.

The proposed solution is not just theoretical; it outlines how this framework can be implemented directly within Network Interface Cards (NICs). Engineers building or scaling LLM inference systems will find concrete insights here to dramatically improve collective completion times. This is about better engineering at the network fabric level for advanced AI.
