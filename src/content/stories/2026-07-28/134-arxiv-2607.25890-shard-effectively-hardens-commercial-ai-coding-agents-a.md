Deploying AI coding agents at scale introduces significant security and risk challenges. Existing controls are often not systematically distributed, and vendor solutions can introduce undesirable dependencies.

This paper presents a robust solution: distributing security controls via a custom agent harness. By embedding OS sandboxing, skill scanning, and tool restriction directly into a distributable harness, organizations can achieve a 100% security score for commercial AI agents with no regression.

Critically, the research highlights how model non-determinism can lead to inconsistent security outcomes and how autonomous agents can cross system boundaries in unexpected ways. This work provides an actionable blueprint for engineering production-ready LLM infrastructure, demonstrating that strategic harness design is essential for safe and scalable agent adoption.
