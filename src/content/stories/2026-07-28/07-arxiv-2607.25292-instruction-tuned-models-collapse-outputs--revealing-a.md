Instruction-tuned large language models, the very ones we rely on for nuanced responses, often fail at a surprisingly basic task: truly sampling from a distribution. Instead, they 'collapse' to a single, deterministic output, even when prompted for variability. This is a critical finding for anyone building with LLMs.

This research highlights a 'KNOWS/DOES split': a model can accurately describe a distribution in one prompt but cannot reliably sample from it with repeated calls. This issue is significantly amplified by alignment training, suggesting an inherent trade-off. For instance, in persona-based tasks, the same query will yield the same response over half the time.

The good news is there are actionable workarounds. By simply asking the model to describe the distribution of responses, error rates against human survey data can be more than halved. This finding fundamentally changes how we should approach sampling and prompt engineering for diverse or persona-driven LLM applications.
