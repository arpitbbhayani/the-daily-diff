Building reliable LLM-based multi-agent systems for high-stakes decisions, such as actuarial risk modeling, demands robust uncertainty quantification. Simply relying on LLMs' probabilistic nature is not enough when outputs can lead to incorrect assessments.

This research introduces a novel framework that tackles this head-on. It proposes using token-level log-probabilities, which are length-normalized and calibrated into task-level confidence estimates, then integrated into a Bayesian Network for comprehensive uncertainty propagation across the entire multi-agent workflow.

This approach not only matches baseline performance but, more importantly, provides crucial runtime insights into workflow stability and inherent uncertainties. It is a significant step towards developing trustworthy and transparent LLM agents for mission-critical applications where reliability is paramount.
