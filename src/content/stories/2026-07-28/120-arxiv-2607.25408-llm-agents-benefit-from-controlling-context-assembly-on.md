Optimizing the 'harness' around a frozen LLM agent - things like prompt templates, few-shot examples, retrieval context, or planning passes - is often more art than science. What if we treated context assembly as a rigorously controlled variable?

This paper introduces a control-theoretic view, formalizing context assembly itself as the controlled variable. An outer policy, learned online with methods like contextual bandits or REINFORCE, dynamically optimizes this context, while the inner LLM model remains frozen. This allows for principled adaptation without costly model fine-tuning or risky self-modifying code.

The work provides a formal decomposition and a stability argument for this online controller, giving engineers a theoretical grounding for robust agent adaptation. It moves beyond heuristics to a more systematic way of making agents learn and adapt to new domains.

For anyone building production LLM agents, this offers a powerful framework for making them smarter and more resilient by intelligently managing their observational context.
