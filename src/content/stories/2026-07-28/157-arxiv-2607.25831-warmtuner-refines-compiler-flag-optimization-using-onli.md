Compiler autotuning is a black art, with hundreds of optimization flags leading to exponentially many combinations. Finding the best configuration for a target program is a huge challenge, often resulting in suboptimal performance.

WarmTuner tackles this with an innovative offline-to-online reinforcement learning framework. It first learns a program-conditioned policy from historical optimal configurations. Then, crucially, it refines this policy online using actual compile-run feedback from the target program itself. This adapts the tuning to real-world speedups, not just static historical data.

The results are compelling: WarmTuner achieves an average speedup of 1.732x over GCC -O3 and secures the best results on nearly half of the evaluated programs. This work demonstrates a powerful paradigm for automated, program-specific performance optimization.

It highlights how combining historical knowledge with real-time adaptation can unlock significant gains in fundamental system tools.
