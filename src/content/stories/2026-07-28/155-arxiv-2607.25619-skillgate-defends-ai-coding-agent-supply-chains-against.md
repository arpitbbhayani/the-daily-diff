AI coding agents are powerful, but their use of "skill files" downloaded from public registries opens a new, critical supply-chain attack surface. Malicious skill files can silently exfiltrate credentials or inject backdoors into generated code.

SkillGate offers a much-needed defense. It is a security gateway that screens AI skill packages before installation using a clever hybrid regex-prefilter and LLM-judge pipeline. This design saves considerable cost: safe files bypass the LLM entirely, and flagged files send only matched snippets to the judge, not full content.

The results are impressive. SkillGate achieves an F1-score of 0.817 with a mere 1.13 percent false positive rate, all while reducing LLM input tokens by 77 percent compared to full-file screening. This is a vital tool for any team deploying coding agents and prioritizing their security.
