Building multi-agent LLM systems often means a tangled mess of agent roles, coordination logic, and collaboration algorithms. This paper introduces IMACS, a framework that masterfully decouples these three concerns into independent, swappable layers.

This separation is a game-changer. It allows engineers to apply classic organizational theory directly to AI agent teams, making concepts like Belbin roles or RACI accountability executable configurations. You can now systematically experiment with organizational structures, holding collaboration protocols constant, to see their true impact.

IMACS also turns protocol choice into a learnable variable. Its Adaptive Org Routing, a contextual-bandit meta-protocol, dynamically selects the best protocol for a given task under explicit quality-cost tradeoffs. This system not only outperforms fixed protocols but also trains online using real benchmarks and LLM-judge rewards.

The critical insight? Organizational design for AI agents is not a one-size-fits-all problem; it must be revalidated or learned for each model and task. This offers a powerful blueprint for architecting scalable, adaptive agent systems.
