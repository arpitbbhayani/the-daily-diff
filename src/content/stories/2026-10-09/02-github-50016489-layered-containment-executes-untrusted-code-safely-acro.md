Executing arbitrary code generated by language models in production requires containment that goes well beyond basic process wrappers. Running untrusted interpreter tasks inside standard Docker containers introduces high latency and resource contention, while bare system calls invite severe security liabilities.

Microsoft execution container addresses this problem by exposing a unified containment layer over native operating system primitives. The system abstracts disparate sandboxing technologies, switching between Bubblewrap on Linux, Seatbelt on macOS, Windows Sandbox, and lightweight MicroVM runtimes such as Hyperlight and Nanvix under a single policy engine.

Engineers can enforce strict filesystem path allowances, egress network policies, and clipboard isolation through declarative JSON configurations. This gives agent harnesses the ability to dial isolation up or down based on risk profile without rewriting execution logic for every host operating system.

Hardening agent infrastructure requires defense in depth at the operating system boundary.
