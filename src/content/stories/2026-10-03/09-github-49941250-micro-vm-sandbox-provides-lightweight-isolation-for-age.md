Running untrusted code generated by AI agents inside standard Docker containers introduces serious security risks. Containers share the host kernel, leaving a wide attack surface that can compromise entire nodes.

Microsoft Systems Research and Azure Research released NVX, an open-source micro-VM sandbox tailored specifically for agentic execution. Built on OpenVMM and running Linux guests, NVX delivers hardware-enforced virtualization boundaries while maintaining the rapid startup speeds demanded by interactive agent loops.

The framework provides a minimal guest kernel, optimized boot paths, and direct Python interfaces. By isolating file system mutations and system calls inside individual lightweight virtual machines, platforms can safely grant coding agents broad terminal capabilities.

Hardware virtualization remains the most reliable boundary for untrusted code execution in multi-tenant agent systems.
