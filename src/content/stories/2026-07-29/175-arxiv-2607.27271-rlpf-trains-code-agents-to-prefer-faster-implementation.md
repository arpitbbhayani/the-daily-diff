Code models are getting good at generating correct code, but "correct" does not always mean "fast." A significant challenge for systems code is training LLM agents to optimize for performance, not just pass tests. RLPF (Reinforcement Learning from Performance Feedback) offers an elegant solution.

The core idea is a staged reward system. Instead of a binary correct/incorrect signal, RLPF orders failed programs by execution progress and ranks correct programs by their relative efficiency improvement. This provides continuous, meaningful feedback even when programs are not fully correct, and highly sensitive feedback once they are.

The results are compelling. Fine-tuning Qwen3-32B with RLPF on PerfCodeBench boosted correct-and-runnable solutions from 11.1 percent to 54.6 percent, and improved relative efficiency from 8.1 percent to 38.6 percent. This shows that code agents can be trained to deeply understand and optimize for runtime characteristics.

If you are building code generation systems, this work demonstrates how to move beyond basic correctness to truly performant and efficient AI-generated code.
