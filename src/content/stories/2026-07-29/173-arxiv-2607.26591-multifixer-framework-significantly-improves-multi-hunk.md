Automated Program Repair (APR) with LLMs often struggles with multi-hunk bugs, those pesky issues requiring changes spread across multiple files or methods. MultiFixer introduces a compelling multi-agent framework that redefines what is possible.

The core innovation is a "Coordinator-Proposer" architecture. One agent orchestrates the bug analysis and repair order, while others propose specific hunk-level patches, enabling a systematic approach to complex problems. This coordinated effort, combined with tool-augmented analysis and two-stage patch refinement, is highly effective.

The results are impressive: MultiFixer sets a new state of the art on Defects4J, fixing 420 bugs when combined with Claude-3.5-Sonnet, including a substantial number of multi-file and multi-method bugs. This is not just an incremental gain; it is a leap forward for agentic capabilities in software engineering.

If you are building code agents, pay attention: a robust multi-agent architecture is the key to cracking truly hard problems.
