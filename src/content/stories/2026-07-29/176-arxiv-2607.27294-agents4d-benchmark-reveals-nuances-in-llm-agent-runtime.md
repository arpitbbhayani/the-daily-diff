Deploying LLM-based agents means confronting runtime risks that extend far beyond initial verification. Agent safety is a continuous concern across its entire execution lifecycle.

AgentS4D introduces a crucial four-dimensional runtime-safety framework. It maps six risk-entry sources, six induction strategies, and nine target harms to guide case construction, all while organizing evidence through seven lifecycle checkpoints.

Crucially, the benchmark of 6,560 runs revealed that task completion does not equal runtime safety, with 66.22 percent of unsafe runs completing tasks. This framework is essential for truly robust agent development.
