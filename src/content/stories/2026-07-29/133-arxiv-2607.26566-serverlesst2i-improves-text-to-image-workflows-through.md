Serving complex AI workflows like Text-to-Image models on serverless platforms often leads to inflated scaling overheads and inefficient GPU utilization due to monolithic designs. A new system, ServerlessT2I, tackles this head-on. It re-architects T2I serving by decomposing workflows into loosely coupled model functions.

This decomposition enables independent, per-model scaling, declarative workflow composition, and transparent GPU-resident communication, drastically cutting down on model loading and data transfer bottlenecks. The system also harvests slack GPU memory to build a highly efficient data plane.

The results are compelling: ServerlessT2I sustains up to 2x higher request rates than existing systems with the same GPU budget, or saves up to 3x GPU resources for a fixed rate. This is a crucial step towards truly scalable and cost-effective generative AI inference, especially for intermittent, customized workflows. Practical system design changes can yield immense performance gains.
