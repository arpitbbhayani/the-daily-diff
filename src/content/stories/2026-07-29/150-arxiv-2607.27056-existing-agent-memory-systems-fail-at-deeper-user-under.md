The true challenge for personalized AI agents is not just retrieving explicit facts; it is inferring abstract user characteristics and understanding behavior patterns from messy, heterogeneous data over time. Current benchmarks largely miss this deeper hierarchical understanding.

Setoka is a new benchmark designed specifically to fill this gap. It evaluates agents across four levels: semantic memory, episodic memory, behavior patterns, and personality traits, using psychometrics-based synthetic data.

The findings are stark: existing systems struggle significantly beyond basic fact retrieval. This benchmark is crucial for driving the development of memory mechanisms that enable agents to achieve genuine, long-term user understanding.
