Long-context LLM inference faces a severe memory wall due to the ever-growing KV cache. Current sparse KV methods offload entries but add significant GPU memory overhead for retrieval management.

DualDecoder solves this with predictive prefetching. It accurately predicts critical KV entries from speculated tokens, overlapping retrieval from host memory with decoding computation.

This eliminates GPU auxiliary state overhead, leading to a 2.62x increase in decoding throughput. For anyone grappling with scaling long-context LLM serving, this system design offers a powerful solution.
