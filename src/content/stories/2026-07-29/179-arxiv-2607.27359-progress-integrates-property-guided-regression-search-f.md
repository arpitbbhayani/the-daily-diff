Traditional search-based regression testing excels at structural coverage but often misses semantic bugs because its oracles are derived from the system under test, recording existing faults as expected behavior.

PROGRESS (PROperty-Guided REgression Search for Semantic Falsification) solves this by integrating LLM-generated, intent-driven properties into coverage-guided evolutionary test generation. It uses a language-model pipeline to generate executable jqwik properties, steering the search towards property falsification.

This novel approach detected 328 out of 562 current-version bugs (58 percent) on 25 large-scale Java systems, compared to zero for regression-test generation alone. It is a powerful method to find deep semantic faults that slip past conventional testing.
