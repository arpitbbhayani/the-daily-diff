Semantic code search is no longer a luxury; it is a necessity for navigating massive codebases. MediaWiki Code2Code Search demonstrates a practical, neural retrieval system that indexes millions of structural entities across 2,500+ repositories.

It intelligently tackles the 'lexical gap' problem where keyword searches fail, enabling discovery based on computational intent. The architecture is a highlight: a split-build approach decouples GPU-intensive indexing from a CPU-only serving layer, allowing for a tiny 168.6 MB FAISS index and sub-2-second query latency.

This is a masterclass in applying deep learning to developer tooling, making code discovery efficient and intuitive. It is open source, too.
