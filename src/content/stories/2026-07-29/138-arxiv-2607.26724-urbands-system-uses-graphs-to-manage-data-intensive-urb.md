Building AI agents for real-world, data-intensive tasks is tough. Traditional methods struggle with large-scale, multi-sourced, and relationally complex data. UrbanDS tackles this by proposing a graph-guided multi-agent system.

It features agents for data profiling, relation identification, planning, and execution, all orchestrated around a unified dataset graph. This graph helps agents discover and leverage relevant information, moving beyond simple reliance on predefined datasets.

The system has been deployed on an urban operations platform, demonstrating its effectiveness in complex, real-world applications. This offers a concrete blueprint for how to engineer robust, data-aware agent systems for practical use cases.
