The promise of truly autonomous LLM agents hinges on effective long-term memory. Many agents default to filesystem-based memory, but its organization, evolution, and sustainability have remained largely untested assumptions.

This paper provides the first systematic exploration, formalizing agent memory around a filesystem with distinct management, search, and execution roles. It empirically analyzes how memory shape, stream scale, and tool harnesses impact answer quality, cost, and, crucially, "store health" as memory grows.

A key finding is that while organization reliably halves retrieval cost, today's agents struggle to maintain it, eroding over time even with dedicated management agents. Surprisingly, merely changing the toolset can reshape the memory store as profoundly as swapping the underlying LLM. This work transforms filesystem memory from a hidden assumption into a critical design space for robust agent systems.
