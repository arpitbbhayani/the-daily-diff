Persistent memory for conversational AI agents is a major hurdle. Injecting full chat histories exhausts context windows, and external services raise privacy concerns. This paper introduces a compelling solution: an agent-local Neo4j property graph, supercharged with HNSW vector indexes and a full bitemporal data model.

This design stores memories as immutable identity nodes linked to versioned content, capturing both "valid time" (when a fact was true) and "transaction time" (when it was recorded). This enables point-in-time semantic retrieval, crucial for handling knowledge updates and complex temporal reasoning.

The system was evaluated on a 500-question benchmark, showing strong recall for current-state and time-travel queries. This approach offers a powerful blueprint for solving long-term memory challenges in your AI agent architectures, blending database rigor with AI needs.
