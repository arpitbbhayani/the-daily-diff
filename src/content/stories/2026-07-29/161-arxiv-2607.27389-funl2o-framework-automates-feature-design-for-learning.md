Hand-crafted features often bottleneck Learning-to-Optimize (L2O) methods. FunL2O changes this by introducing the first unified framework for automating feature design using LLM-driven program evolution, a groundbreaking approach.

This framework operates in a FunSearch-style loop: an LLM proposes executable feature functions, which are then evaluated by retraining the original L2O model to measure downstream optimization performance. This creates a powerful feedback loop for continuous improvement.

FunL2O consistently outperforms hand-crafted representations across linear, quadratic, and mixed-integer optimization tasks. For engineers working on complex optimization problems or looking to automate ML pipeline components, this offers a compelling new paradigm to accelerate development and boost solver efficacy.

LLMs are becoming powerful tools for meta-optimization.
