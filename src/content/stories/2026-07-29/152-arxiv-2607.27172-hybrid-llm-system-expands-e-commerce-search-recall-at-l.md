Improving e-commerce search discoverability often means balancing precision with recall. A new scalable system shows how to achieve this by generating related user intents, going beyond strict query matching.

The approach uses a two-stage hybrid architecture: large language models (LLMs) for head queries and fine-tuned small language models (SLMs) via LoRA and distillation for tail queries. This innovation extends discovery coverage from 60 percent to 80 percent of query traffic, all while maintaining only 30 percent of the teacher model's inference cost.

This is a masterclass in practical LLM infrastructure and system design, offering a blueprint for deploying powerful AI capabilities at scale without breaking the bank. It is about smart architecture, not just bigger models.
