LLM-based agents excel at modifying existing codebases but struggle with program synthesis from scratch. Existing single-pass approaches often lead to insufficient probing, context drift, and propagating early misinterpretations.

SpecFirst offers a paradigm shift: behavioral specification elicitation should be a first-class phase. A dedicated spec agent first probes the binary and documentation to generate a structured specification, which then guides a separate code synthesis agent.

This decomposition resolves ambiguities before coding begins, providing a stable behavioral reference. It consistently outperforms single-loop baselines, improving test pass rates by 6.9-21.3 percent and binary exploration coverage by 9.4-18.5 percent. It is the requirements engineering phase that modern coding agents desperately need.
