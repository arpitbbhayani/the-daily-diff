Imagine an ASR system that gets smarter and more reliable over time, without retraining the core model. 'Voice Memory' achieves this with an inference-only scheme using a separate, editable 'memory.md' file.

This 'listener-thinker' architecture decouples the main ASR model from a corrective, learned memory. An asynchronous optimizer refines this memory, accepting edits only if they strictly improve performance. This not only boosts accuracy (e.g., 8.40% to 3.40% for air-travel commands) but, crucially, reduces over-correction, making it robust and auditable for real-world agentic applications.
