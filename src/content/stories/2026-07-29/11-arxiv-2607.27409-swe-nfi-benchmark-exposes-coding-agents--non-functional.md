Coding agents excel at functional correctness, but how do they fare with non-functional improvements (NFIs)? A new benchmark, SWE-NFI, reveals a significant gap: current coding agents fall far short of human developers in improving code quality without changing behavior.

This benchmark, built from 188 real-world Python pull requests and evaluated with 92 executable rules, highlights critical areas where agents struggle. Specifically, for structural code improvements, agents score 0.0 to 1.3, compared to a human reference of 1.5.

For senior engineers and leaders looking to integrate AI into development workflows, these findings are essential. It means we cannot yet rely on agents for nuanced code quality enhancements, and future agent development must prioritize these NFI capabilities to truly augment developer productivity.

The path to fully autonomous code refinement is longer than we thought.
