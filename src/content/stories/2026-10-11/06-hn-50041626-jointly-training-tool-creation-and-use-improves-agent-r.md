Most tool-augmented large language models remain bottlenecked by the static interfaces written by human engineers. When researchers attempt to let models generate their own tools at inference time, the tool creator is usually decoupled from the tool consumer. This lack of feedback causes schema mismatches and invocation failures.

The SMITH framework resolves this decoupling by treating tool creation and tool execution as a unified reinforcement learning loop inside a single policy. Instead of freezing the model, rollouts alternate between authoring code based on examples and executing pooled tools on held-out reasoning problems. The optimization uses three independent reward axes to isolate schema definition errors, runtime code crashes, and incorrect task outcomes. Each failure mode produces targeted gradients back to the policy.

This dual optimization allows a compact four-billion parameter model to reach nearly eighty percent macro-average accuracy on unseen procedural tasks, surpassing untrained models an order of magnitude larger. Furthermore, tools generated by this policy generalize effectively to smaller frozen downstream models without schema degeneration.

Training models to use tools is useful, but teaching them to build the tools they consume changes the ceiling of agent autonomy.
