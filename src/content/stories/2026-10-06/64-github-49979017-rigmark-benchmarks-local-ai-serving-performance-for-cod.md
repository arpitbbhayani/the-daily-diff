Standard LLM serving benchmarks often fail to reflect the actual load generated by autonomous coding agents. Synthetic token throughput tests overlook critical factors like KV-cache prefill hits, cache-busting replays, and strict structured output constraints.

RigMark is an open-source benchmarking tool built specifically to address this gap for OpenAI-compatible local serving engines such as vLLM and SGLang. Instead of measuring generic streaming speeds, it tests multi-turn agent interaction patterns, structured output decoding penalties, and multi-tenant concurrent execution.

Running reproducible benchmarks against real agent query distributions reveals surprising bottlenecks in KV cache reuse and structured grammar validation that synthetic metrics hide. It gives engineering teams verifiable numbers before deploying local models to developer workflows.

Benchmarking local inference requires workloads that mimic real agent workflows rather than synthetic token generation counters.
